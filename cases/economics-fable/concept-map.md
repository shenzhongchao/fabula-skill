# 经济学概念图

## 1. 学科范围与中心问题

经济学研究人在资源有限、信息不完全、规则不稳定的条件下，如何做选择、如何交换、如何合作、如何竞争，以及这些个体行为如何汇聚成价格、市场、制度和宏观结果。它的中心问题是：当想要的东西总是多于可得的东西时，什么样的选择会形成更好的秩序，什么样的规则会让结果变坏。

这份概念图聚焦适合寓言化写作的核心经济学结构，优先保留能够直接转化为故事冲突、选择后果和制度变化的概念。微观经济学、博弈论、制度经济学和基础宏观概念是主线；更细的计量方法、复杂模型、金融工程和高级宏观框架只作为延伸关系，不展开为完整分支。

## 2. 全局结构

### 逻辑层次

1. 选择的根：稀缺、选择、机会成本、边际思维、激励。
2. 交换与分工：分工、专业化、比较优势、交换、交易成本。
3. 价格与市场：需求、供给、价格、均衡、弹性、剩余。
4. 生产与竞争：成本、边际成本、规模经济、利润、竞争、垄断。
5. 信息与风险：不确定性、信息不对称、逆向选择、道德风险、信号、筛选、有限理性。
6. 合作与博弈：策略互动、囚徒困境、协调问题、搭便车、公共品、公地悲剧、重复博弈、声誉。
7. 制度与宏观背景：产权、契约、执行机制、制度、外部性、税收与补贴、货币、通货膨胀、失业、经济增长、路径依赖。

### 寓言化优先级

1. 最适合直接写成寓言的概念：稀缺、机会成本、激励、交换、交易成本、价格、信息不对称、囚徒困境、搭便车、产权、外部性。
2. 适合和前述概念成组写作的概念：比较优势、需求与供给、均衡、边际成本、垄断、逆向选择、道德风险、公共品、公地悲剧、声誉、制度。
3. 更适合后期写作或作为解释段补充的概念：弹性、消费者剩余、生产者剩余、规模经济、有限理性、执行机制、货币、通货膨胀、失业、经济增长、路径依赖。

## 3. 依赖总览

经济学寓言最好从稀缺开始，因为只有资源有限，选择才会有代价，机会成本才会显形。选择和激励决定一个人会怎么行动；交换和分工让多个选择连成网络；价格、供给和需求则把许多个体的偏好压缩成可见信号。接着，生产、成本和竞争说明为什么某些行动会持续、某些会退出；信息不对称和风险揭示为什么看似公平的交易会失真。最后，博弈、公共品、产权和制度把故事提升到群体层面，说明规则怎样塑造长期结果，外部性和路径依赖怎样让局部选择变成整个共同体的命运。

## 4. 概念条目

### 4.1 选择的根

### C01 - 稀缺

- ID: C01
- Summary: 稀缺是经济学最底层的起点。它表示人想要的东西、可用的时间和手里的资源之间总有缺口，所以任何满足都必须先处理取舍。
- Layer: 选择的根
- Predecessors: 无
- Successors: C02, C03, C04, C05
- Historical or logical position: 全部经济分析的起点
- Source evidence: 基础经济学教材的核心假设
- Confidence: 高
- Key relationships: 让选择变得必要；为机会成本和激励提供前提
- Common misunderstandings: 把稀缺只理解成“钱不够”；实际上时间、注意力、土地、信用都可能稀缺
- Fable hooks: 一间铺子里的每个货架都比空出来的地方更想被占用

### C02 - 选择

- ID: C02
- Summary: 选择是把有限资源放在某一条路上，同时放弃其他路。它看起来简单，却总带着代价，因为每次决定都会关上别的可能。
- Layer: 选择的根
- Predecessors: C01
- Successors: C03, C04, C05, C06
- Historical or logical position: 经济行为的基本动作
- Source evidence: 基础消费理论与生产理论
- Confidence: 高
- Key relationships: 机会成本与边际思维都建立在选择之上
- Common misunderstandings: 以为选择只是偏好表达；实际上它总受约束
- Fable hooks: 赶集的人只能先停在一个摊前，别的摊就暂时错过了

### C03 - 机会成本

- ID: C03
- Summary: 机会成本不是账面上直接付出去的东西，而是为了选中一件事而错过的最好替代方案。它把“没做什么”的代价也算进来。
- Layer: 选择的根
- Predecessors: C01, C02
- Successors: C04, C06, C18, C23
- Historical or logical position: 选择分析的核心概念
- Source evidence: 决策理论与成本分析
- Confidence: 高
- Key relationships: 让“免费”这件事变得可疑；连接选择和投入
- Common misunderstandings: 把机会成本当成已经花掉的钱
- Fable hooks: 选了修桥，就没有空去修井

### C04 - 边际思维

- ID: C04
- Summary: 边际思维问的不是“要不要做”，而是“再多做一点值不值”。它关注增量，而不是一次性的大判断。
- Layer: 选择的根
- Predecessors: C01, C02, C03
- Successors: C05, C18, C20, C22
- Historical or logical position: 决策分析的关键转折
- Source evidence: 边际效用与边际成本分析
- Confidence: 高
- Key relationships: 和 C18、C20、C22 直接连通
- Common misunderstandings: 以为边际分析只是精细算账；其实它是行动方式
- Fable hooks: 还要不要再添一篮柴，比“要不要生火”更能决定今晚的结局

### C05 - 激励

- ID: C05
- Summary: 激励是规则、奖赏、惩罚和环境一起给人的方向感。人并不总按口号行动，常常顺着最实际的回报与损失行动。
- Layer: 选择的根
- Predecessors: C01, C02, C04
- Successors: C06, C10, C30, C48
- Historical or logical position: 连接个体行为与制度结果
- Source evidence: 激励理论、委托代理问题
- Confidence: 高
- Key relationships: 和信息不对称、道德风险紧密相连
- Common misunderstandings: 把激励只理解成奖金；处罚、声誉、便利性也是激励
- Fable hooks: 同样一筐果子，按件算和按筐算，人的手劲会完全不同

### 4.2 交换与分工

### C06 - 分工

- ID: C06
- Summary: 分工是把一件完整的事拆开，让不同的人各做其中一部分。它通常能提高效率，但也会让每个人更依赖别人。
- Layer: 交换与分工
- Predecessors: C02, C03, C05
- Successors: C07, C08, C09, C10
- Historical or logical position: 市场形成前后的基础组织方式
- Source evidence: 亚当·斯密关于分工的经典论述
- Confidence: 高
- Key relationships: 依赖比较优势和交换
- Common misunderstandings: 以为分工只是把事情切碎；关键是协作后总产出更高
- Fable hooks: 一条街上有人只打铁，有人只磨刀，有人只送货

### C07 - 专业化

- ID: C07
- Summary: 专业化是分工进一步固定下来后，某些人把一类活做得更熟、更快、更稳。它能提升熟练度，也会增加路径依赖。
- Layer: 交换与分工
- Predecessors: C06
- Successors: C10, C18, C21
- Historical or logical position: 分工的深化结果
- Source evidence: 生产组织与劳动经济学
- Confidence: 高
- Key relationships: 和规模经济常常一起出现
- Common misunderstandings: 以为专业化只等于狭窄；它也可能带来高质量
- Fable hooks: 同一只手天天系绳子，最后比谁都快

### C08 - 比较优势

- ID: C08
- Summary: 比较优势不是看谁绝对更强，而是看谁做某件事放弃得更少。它说明交换为什么对双方都可能有利。
- Layer: 交换与分工
- Predecessors: C03, C06
- Successors: C09, C10
- Historical or logical position: 国际贸易与分工分析的基础
- Source evidence: Ricardo 的比较优势理论
- Confidence: 高
- Key relationships: 是交换与贸易故事最常见的转轴
- Common misunderstandings: 以为弱者才有比较优势；强者也有，只是方向不同
- Fable hooks: 会种地的人不一定最会修鞋，但也许种地时放弃得更少

### C09 - 交换

- ID: C09
- Summary: 交换是双方把自己多余而别人更需要的东西换出去。它能让双方都更接近自己想要的状态。
- Layer: 交换与分工
- Predecessors: C06, C08
- Successors: C10, C11, C12, C13
- Historical or logical position: 市场关系的直接形式
- Source evidence: 市场交易与贸易理论
- Confidence: 高
- Key relationships: 交换把分工变成真实收益
- Common misunderstandings: 以为交换必有赢家和输家；很多交换是双赢，但前提是规则清楚
- Fable hooks: 两家铺子各自抱着用不上的货，换完后都轻快了

### C10 - 交易成本

- ID: C10
- Summary: 交易成本是为了完成交换而额外付出的搜寻、谈判、运输、核验和执行代价。它常常决定一笔看似合理的交易最后能不能成立。
- Layer: 交换与分工
- Predecessors: C05, C06, C09
- Successors: C28, C42, C44, C45
- Historical or logical position: 市场组织的重要摩擦
- Source evidence: 交易成本经济学
- Confidence: 高
- Key relationships: 和制度、契约、执行机制直接相关
- Common misunderstandings: 把交易成本只理解成手续费；实际上信任和时间也算
- Fable hooks: 买卖没成，不一定是价钱不对，也可能是来回跑腿太累

### 4.3 价格与市场

### C11 - 需求

- ID: C11
- Summary: 需求不是单纯想要，而是愿意在某个价格或条件下真正去买。它把偏好和支付能力连在一起。
- Layer: 价格与市场
- Predecessors: C02, C09
- Successors: C13, C14, C15, C16
- Historical or logical position: 市场分析的左侧力量
- Source evidence: 微观经济学需求理论
- Confidence: 高
- Key relationships: 与供给一起决定价格
- Common misunderstandings: 把需求当成抽象愿望；真正的需求包含行动
- Fable hooks: 口头说想要的人很多，肯掏钱的人才会留下痕迹

### C12 - 供给

- ID: C12
- Summary: 供给是愿意拿出多少东西去卖，取决于成本、能力和预期回报。它告诉我们一件东西到底有多少会出现在市场上。
- Layer: 价格与市场
- Predecessors: C02, C05, C09
- Successors: C13, C14, C15, C17
- Historical or logical position: 市场分析的右侧力量
- Source evidence: 微观经济学供给理论
- Confidence: 高
- Key relationships: 与需求共同决定市场结果
- Common misunderstandings: 把供给看成库存本身；其实供给是愿意出售的行为
- Fable hooks: 仓库里有货，不等于货愿意在这个价上出来

### C13 - 价格

- ID: C13
- Summary: 价格是许多信息被压缩后的结果。它告诉人们什么东西更稀缺、什么行动更值得、哪里该增加供给、哪里该减少需求。
- Layer: 价格与市场
- Predecessors: C11, C12
- Successors: C14, C15, C16, C17
- Historical or logical position: 市场协调的核心信号
- Source evidence: 供需模型
- Confidence: 高
- Key relationships: 把局部偏好变成公共信号
- Common misunderstandings: 以为价格只是标签；它同时是信息和激励
- Fable hooks: 一块木牌就能让整条街改变动作

### C14 - 均衡

- ID: C14
- Summary: 均衡是需求和供给在某个价格上暂时对上，没人被迫改口就能继续发生交易的状态。它不是永恒静止，而是暂时稳定。
- Layer: 价格与市场
- Predecessors: C11, C12, C13
- Successors: C15, C16, C17, C18
- Historical or logical position: 市场分析的平衡点
- Source evidence: 供需均衡模型
- Confidence: 高
- Key relationships: 为市场波动提供参照
- Common misunderstandings: 把均衡看成完美；它只是暂时最不别扭的安排
- Fable hooks: 集市上排队终于不再一长一短

### C15 - 弹性

- ID: C15
- Summary: 弹性描述价格或条件一变，需求和供给会不会立刻跟着变。它反映的是行为有多容易被撬动。
- Layer: 价格与市场
- Predecessors: C13, C14
- Successors: C48, C50
- Historical or logical position: 市场反应强度的刻画
- Source evidence: 需求弹性与供给弹性理论
- Confidence: 高
- Key relationships: 影响税收、补贴和政策效果
- Common misunderstandings: 以为弹性只是“敏不敏感”；本质上是可替代性和调整空间
- Fable hooks: 有些东西一贵，大家立刻转身；有些东西再贵也得买

### C16 - 消费者剩余

- ID: C16
- Summary: 消费者剩余是得到的满足超过实际付出的那部分好处。它说明交易并不只是刚好成交，还可能带来额外收益。
- Layer: 价格与市场
- Predecessors: C13, C14, C15
- Successors: C23, C48
- Historical or logical position: 福利分析的一部分
- Source evidence: 福利经济学
- Confidence: 高
- Key relationships: 和价格、需求关系最紧
- Common misunderstandings: 把它误解成现金余额；其实是主观净收益
- Fable hooks: 有人买到一把伞时，心里觉得比掏出去的钱更值

### C17 - 生产者剩余

- ID: C17
- Summary: 生产者剩余是卖出所得超过愿意接受的最低代价的部分。它说明生产者为什么愿意继续把东西拿出来卖。
- Layer: 价格与市场
- Predecessors: C12, C13, C14
- Successors: C18, C23
- Historical or logical position: 福利分析的一部分
- Source evidence: 福利经济学
- Confidence: 高
- Key relationships: 和利润相近，但不完全相同
- Common misunderstandings: 把它等同于会计利润；它更接近交易中的净得益
- Fable hooks: 卖掉一筐果子后，摊主觉得这趟没有白起早

### 4.4 生产与竞争

### C18 - 成本

- ID: C18
- Summary: 成本不只是花出去的钱，也包括时间、精力、材料、风险和被占住的资源。它决定一件事能不能长久做下去。
- Layer: 生产与竞争
- Predecessors: C03, C04, C14
- Successors: C19, C20, C21, C22, C23
- Historical or logical position: 生产判断的基础
- Source evidence: 生产理论与成本理论
- Confidence: 高
- Key relationships: 是利润、规模和边际分析的前提
- Common misunderstandings: 把成本只看成账本上的数字
- Fable hooks: 一只桶装满水不难，难的是一路端过去还不洒

### C19 - 固定成本与可变成本

- ID: C19
- Summary: 有些成本一开始就必须先付，有些则会随着产量增加而增加。把二者分开，才能看清生产节奏。
- Layer: 生产与竞争
- Predecessors: C18
- Successors: C21, C23, C25
- Historical or logical position: 成本结构分析
- Source evidence: 企业成本理论
- Confidence: 高
- Key relationships: 决定起步门槛和扩产节奏
- Common misunderstandings: 以为所有成本都能随着产量同步变化
- Fable hooks: 先得把炉子砌好，火候才谈得上多烤几批饼

### C20 - 边际成本

- ID: C20
- Summary: 边际成本是再多做一个单位需要多付出的成本。它让人看到扩张是不是开始变得不划算。
- Layer: 生产与竞争
- Predecessors: C04, C18, C19
- Successors: C21, C22, C23, C24
- Historical or logical position: 产量决策的核心指标
- Source evidence: 成本曲线分析
- Confidence: 高
- Key relationships: 与边际收益一起决定行动是否继续
- Common misunderstandings: 以为边际成本就是平均成本
- Fable hooks: 已经烧起来的炉子，再添一块木头值不值

### C21 - 规模经济

- ID: C21
- Summary: 规模经济指做得越多，平均成本可能越低。它能让大规模生产更有优势，但也可能让小者更难生存。
- Layer: 生产与竞争
- Predecessors: C07, C19, C20
- Successors: C24, C25, C46
- Historical or logical position: 生产组织的重要现象
- Source evidence: 企业规模与平均成本分析
- Confidence: 高
- Key relationships: 和专业化、垄断、路径依赖常常相连
- Common misunderstandings: 把规模经济理解成“越大越好”；超过一定点后未必如此
- Fable hooks: 一口大锅煮得多，摊到每碗上的柴火钱就少了

### C22 - 边际收益递减

- ID: C22
- Summary: 边际收益递减说的是，投入刚加上去时常常很有效，但越往后，每多一点投入带来的好处会越来越少。它提醒人不要把有效的方法无限重复下去。
- Layer: 生产与竞争
- Predecessors: C04, C18, C20
- Successors: C23, C24, C52
- Historical or logical position: 生产与投入决策中的普遍规律
- Source evidence: 生产函数与农业/工业经验
- Confidence: 高
- Key relationships: 和边际成本一起决定最优点
- Common misunderstandings: 以为任何投入都会一直有效
- Fable hooks: 再浇一瓢水，菜未必更快长，地反而先泡软了

### C23 - 利润与亏损

- ID: C23
- Summary: 利润表示一项活动在扣除成本后还剩下多少好处，亏损则说明资源没有被放到最合适的位置。它们都是信号，不只是结果。
- Layer: 生产与竞争
- Predecessors: C03, C16, C17, C18, C20
- Successors: C24, C25, C46
- Historical or logical position: 市场选择的反馈机制
- Source evidence: 企业会计与经济利润分析
- Confidence: 高
- Key relationships: 把选择、成本和价格连接起来
- Common misunderstandings: 把会计利润和经济利润混为一谈
- Fable hooks: 有的铺子看着忙，其实一算账，脚底下已经在漏水

### C24 - 竞争

- ID: C24
- Summary: 竞争是多个行动者争夺顾客、资源或位置时形成的压力。它会逼人改进，也会让弱者被挤出局。
- Layer: 生产与竞争
- Predecessors: C13, C20, C21, C23
- Successors: C25, C46, C48
- Historical or logical position: 市场动态的常态力量
- Source evidence: 市场结构理论
- Confidence: 高
- Key relationships: 与垄断互为对照
- Common misunderstandings: 把竞争浪漫化；竞争也可能导致浪费、模仿和过度消耗
- Fable hooks: 同一条街上太多摊位都在喊价，最后没人能装作听不见

### C25 - 垄断

- ID: C25

## 6. 覆盖说明

- 本图刻意把“经济学”处理成寓言写作可用的概念底盘，因此优先保留可通过人物、场景和后果来呈现的概念，而不是尽可能完整地覆盖学科全貌。
- 本图以微观经济学、博弈论、制度经济学和基础宏观概念为主；计量经济学、复杂金融工具、动态随机一般均衡、现代增长模型细节和高级国际金融没有展开。
- 一些概念之间在现实教材中有不同分法，例如消费者剩余、生产者剩余、利润、经济利润和会计利润的边界。这里为了后续寓言写作，保留最容易讲清的版本。
- 若后续写作偏向财政、货币或国际贸易，可以再单独加分支；若偏向行为经济学，也可以把有限理性、偏差、启发式和心理账户扩展成独立层。
- Source evidence 采用通行教材和经典理论线索，如 Smith、Ricardo、Marshall、Walras、Keynes、Hayek、Coase、Stiglitz、Akerlof、Kahneman 等相关工作，以及供需分析、交易成本、博弈论、公共品、产权、货币和宏观稳定性的标准教材框架。若要写成学术教材，应补充精确论文与页码。
