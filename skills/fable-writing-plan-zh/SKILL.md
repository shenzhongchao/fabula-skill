# 寓言写作计划

## 概览

把概念图谱转化为可执行的写作计划。每个概念对应一则寓言，全篇约 1000 字、且包含正文后的讲解。章节必须按照概念之间的前驱后继关系排序：先学的概念排在前面，依赖它的概念排在后面，而不是松散地罗列主题或照抄资料目录。

“约 1000 字”是把整则寓言（故事正文 + 讲解）作为一个交付单元来衡量的目标篇幅，让全书节奏统一、每个概念都得到足够而不过量的展开。计划阶段只写故事前提和短篇草稿种子，但要在卡片和验收标准里写明这个篇幅目标，供 `fable-writing` 起草、`fable-review` 验收时对照。

## 输入

- 概念图谱。
- 目标读者水平：小学、初中、高中、大学，或自定义读者画像。
- 写作风格和篇幅限制。
- 指定的章节数量或输出范围。

## `plan.md` 必备部分

1. 项目简介：读者、风格、单则寓言约 1000 字（含讲解）的篇幅目标、概念图谱来源和输出要求。
2. 章节组织：按概念的前驱后继关系排序——每章先列出它依赖的前置概念已在哪些更早的章节出现，再列出本章为后续哪些概念奠定基础，使阅读顺序与概念依赖顺序一致。
3. 概念卡片：每个概念一张卡片，包含概念、故事前提、短篇草稿、依赖关系和篇幅目标。
4. 概念覆盖表：列出每个章节计划写入的概念。
5. 验收标准：分别列出单章标准和全书标准。
6. 进度追踪：计划中、已起草、已审阅、已修改、已验收。
7. 输出路径：记录每章草稿和审阅意见的写入位置。

## 短篇草稿风格

每个“短篇草稿”本身就必须像一则真正的寓言，而不是伪装成故事的解释性提纲。

- 通过故事间接讲清目标概念。寓言正文不要出现概念名或学科术语。
- 让读者逐渐意识到隐藏的模式，最好接近结尾时才领会。
- 明确的概念解释放在正文之后，不要塞进故事。
- 文字要具体、易读，质量足以成为出版级文本的基础。

每则寓言的成稿目标是约 1000 字，故事正文与讲解合起来计算。给一个可参照的分配：故事正文约 700–800 字，正文后的讲解约 200–300 字。这只是节奏参考而非硬性配额——概念关系复杂时正文可以更长，简单时可以更短，但全篇不要明显超过 1200 字或低于 800 字，以免某些概念被草草带过、另一些被过度铺陈。计划里的“短篇草稿”只需写出能撑起这个篇幅的故事种子（核心场景、冲突、转折、收束意象），不必写满 1000 字。

## 章节卡片模板

```markdown
### 第 N 章：暂定标题

- 概念组：
- 概念 ID：
- 依赖于：
- 为以下概念奠定基础：
- 目标读者：
- 参考作品：
- 共同冲突结构：
- 可借用元素：
- 应避免元素：
- 故事前提：
- 短篇草稿：
- 篇幅目标：约 1000 字（故事正文约 700–800 字 + 讲解约 200–300 字）
- 正文中必须保持隐含的概念：
- 正文后的解释要点：
- 验收标准：
- 状态：计划中
```

## 规划规则

- 优先写能够为后续概念奠定基础的概念，并据此确定章节顺序：任一概念出场时，它依赖的前驱概念都应已在更早的章节讲过，读者不需要后翻或预先知道尚未出现的概念。
- 每个概念的验收标准里写明约 1000 字（含讲解）的篇幅目标，使 `fable-review` 能直接核对篇幅是否失衡，而不仅是判断概念是否讲清。
- 写每个故事前提之前，先寻找具有相似冲突的大众熟悉作品。优先选择通俗、情节直观、无需额外背景知识的小说或电影；科幻作品最佳，例如《三体》《降临》。避免冷门名著、主要依赖抽象象征的作品，以及必须了解复杂思想背景才能理解的作品。
- 概念覆盖矩阵每行对应一个概念 ID，每列对应一个章节。
- 为章节草稿和审阅意见使用稳定路径，例如 `drafts/chapter-01.md` 和 `reviews/chapter-01-review.md`。
- 尽量沿用概念图谱中的术语，使概念 ID 无需转换即可复用。


## 故事禁用套路

### 意象

避免：钟、河流、镜子、迷宫、织机、地图、灯塔、棋盘、回声、影子、沙漏、风、蜡烛、种子、桥、星星、蝴蝶、蛛网。

### 地点

不要写成“回声城”“记忆之村”“遗忘之海”“寂静谷”这类过度文学化的虚构地名。用普通地名，或者干脆不命名。

### 结构

- 旅人求智于智者
- 村庄异象 -> 众人顿悟
- 孩子一句话点醒大人
- 师徒辩难
- 临终遗言

### 角色

钟表匠、图书管理员、隐士、说书人、老船夫、酿酒师、铁匠、抄经人。

### 开头

不要用“从前有个地方……”“某天某人遇见某事……”“在很远的山里……”这类起手式。直接进入场景。

## 常见错误

- 让概念在其前驱尚未讲过的章节提前出场，迫使读者预先知道还没出现的概念。
- 各概念篇幅严重不均：有的寓言只有两三百字草草带过，有的膨胀到两三千字，偏离约 1000 字（含讲解）的统一目标。
- 围绕术语规划故事，而不是围绕冲突、选择和后果。
- 选择读者不熟悉、需要大量解释的作品作为参照。
- 在寓言正文铺垫充分之前，短篇草稿就直接解释或说出概念。
- 忘记追踪审阅状态。
