
# 科学哲学与统计推断
回答一个核心问题：**科学知识如何增长，统计推理又凭什么把数据变成证据？**

## 第〇层：三大元问题

一切讨论的起点是三个相互关联的元问题：

1. **科学划界问题** —— 科学与伪科学/非科学的界限在哪里？
2. **知识的增长问题** —— 科学知识是如何进步的？
3. **统计推断的逻辑问题** —— 从数据到理论，正确的推理方式是什么？

> 这三个问题构成了全书的逻辑起点。前半部分回应前两个问题，后半部分回应第三个问题。

---

## 第一部分：科学哲学

### 第一层：认识论基础（所有科学哲学的共同前提）

| 概念 | 核心内容 | 关系与影响 |
|------|---------|---------|
| **休谟的归纳问题** | 从有限观察无法逻辑推出普遍规律；过去成功不能证明未来也会成功 | → 直接催生波普尔的可错论与证伪主义；→ 贝叶斯学派对归纳问题的数学回应 |
| **逻辑实证主义** | 维也纳学派的立场：有意义陈述 = 分析真命题 + 可经验证实的命题 | → 波普尔以其为对立面发展出自己的哲学；→ 操作性定义成为经验研究的重要方法论工具 |
| **可证实性原则** | 一个陈述有意义当且仅当可被经验证实 | → 被波普尔替换为“可证伪性”；→ 无法区分科学与伪科学 |
| **理论负载性** | 所有观察都预设了某种理论或偏见，不存在“纯粹”的观察 | → 波普尔：科学从猜想开始而非观察；→ 库恩：范式决定了能看到什么 |
| **发现的情境与辩护的情境** | 理论如何被想到（发现问题）与理论如何被评价（逻辑问题） | → 波普尔关注后者；→ 库恩拒斥这一区分 |

---

### 第二层A：波普尔——可证伪性纲领

**逻辑前提**：休谟归纳问题 + 对逻辑实证主义的批判

| 概念 | 定义与要点 | 关系与影响 |
|------|-----------|---------|
| **可错论** | 我们的任何信念都可能是错的；确定性不是科学的目标 | → 科学的目标不是证明真理，而是排除错误 |
| **可证伪性** | 一个理论是科学的，当且仅当它排除了某些可能的观察；即它“冒险做出了预测” | → 科学的划界标准；→ 精神分析、马克思主义因不可证伪而被质疑 |
| **证伪不对称性** | 观察不能证实普遍理论，但可以证伪它；一只黑天鹅可以推翻“所有天鹅皆白” | → 科学推理是演绎而非归纳的 |
| **猜想与反驳** | 科学过程 = 大胆提出猜想 → 严格尝试证伪 → 被证伪后提出新猜想 | → 知识增长的唯一途径是批判性讨论 |
| **确证** | 通过严峻检验的理论获得“确证”，但绝非被“证明”；只是证明了其经受考验的能力 | → 与“验证”根本不同；→ 理论应被暂时接受但随时准备被推翻 |
| **证伪主义态度** | 不仅理论在形式上可证伪，科学共同体也必须主动尝试证伪理论 | → 区分真假科学的关键在于共同体文化 |
| **形而上学框架** | 科学研究预设的不可直接检验的基本信念，如实在论与工具主义 | → 库恩发展为“范式”概念 |
| **操作性定义** | 用测量程序定义概念；需注意测量不等于定义 | → 经验研究中的核心方法论工具 |

---

### 第二层B：库恩——范式理论

**逻辑前提**：波普尔未能解释科学实践中理论的稳定性；历史案例显示，科学家并不总是立刻放弃遇到反常的理论。

| 概念 | 定义与要点 | 关系与影响 |
|------|-----------|----------|
| **范式-狭义** | 科学共同体共享的范例或标准实验程序，如 DRM 范式、人工语法范式 | ← 波普尔的形而上学框架 |
| **范式-广义** | 科学共同体共享的全部信念、价值观和技术，如行为主义 | → 决定什么问题值得研究、什么算解答 |
| **前科学** | 尚未形成统一范式的阶段，各学派争论不休 | → 范式的出现标志着学科成熟 |
| **常规科学** | 在范式框架内进行的“解谜”活动；范式规定了问题和方法 | ← 波普尔的批判传统在此被“悬置” |
| **反常** | 与范式预测不符的观察结果 | → 积累引发危机 |
| **危机** | 反常持续积累，科学家对范式信心动摇 | → 催生新范式 |
| **科学革命** | 旧范式被新范式取代的转换过程 | ← 非常规科学时期 |
| **不可通约性** | 不同范式的概念系统无法完全翻译；各自定义了问题和数据 | ← 后期库恩弱化为“概念指称差异” |
| **格式塔转换/皈依** | 范式转换类似视知觉重组；新范式让人“看见”不同的世界 | ← 早期库恩的激进表述 |
| **共享评价标准** | 后期库恩提出的跨范式标准：精确性、一致性、广度、简单性、丰富性 | ← 回应相对主义批评；→ 为理性理论选择留空间 |
| **相对主义** | 早期库恩被解读为“真理由科学共同体决定”，引发后现代和社会建构主义争议 | ← 本书对此进行了系统批判 |

**波普尔与库恩的核心分歧**：

- 策略分歧：波普尔主张直接攻击理论核心；库恩主张核心稳定、修正辅助假设。
- 态度分歧：波普尔认为科学家持猜想态度；库恩认为科学家需要对范式有信任。
- 划界分歧：波普尔以“批判传统”划界；库恩以“解谜能力”划界。

### 第二层C：拉卡托斯——研究纲领方法论

**逻辑前提**：融合波普尔的理性主义、库恩的历史分析，以及对硬核和保护带的区分。

| 概念 | 定义与要点 | 关系与影响 |
|------|-----------|------|
| **研究纲领** | 比单个理论更大、比范式更结构化的评价单元 | ← 波普尔的理论 + 库恩的范式 |
| **硬核** | 纲领中不可直接放弃的核心信念 | ← 库恩的范式核心 |
| **保护带** | 围绕硬核的辅助假设，承受经验检验的压力，可被调整或替换 | ← 科学家面对反常时的实际做法 |
| **正面启发法** | 指导如何修改保护带的策略或原则 | ← 纲领内部的研究方法论 |
| **进步性纲领** | 持续做出新颖预测且部分被确证的纲领 | → 应被选择继续研究 |
| **退化性纲领** | 仅事后解释、无法预测新事实的纲领 | → 应被放弃 |
| **案例法与成文法** | 哲学方法论应既受普遍原则约束，又向历史案例学习 | ← 波普尔的普遍主义与库恩的历史主义 |

## 第二部分：统计推断

### 第三层：概率的哲学基础（统计推断的共同前提）

| 概念 | 核心内容 | 关系与影响 |
|------|---------|---------|
| **概率公理** | P(A) >= 0；P(S) = 1；P(A 或 B) = P(A) + P(B)；P(A 且 B) = P(A) × P(B\|A) | → 所有流派的数学基础 |
| **主观概率** | 概率 = 对命题的信念程度，在心智中 | → 贝叶斯方法 |
| **客观概率** | 概率 = 世界的客观性质，不在心智中 | → 内曼-皮尔逊方法 |
| **长期相对频率** | 概率 = 无限次重复事件中某结果的相对频率 | → 频率主义统计 |
| **参考类/集合** | 概率附着于事件集合而非单个事件；单个事件无概率 | → 无法谈论 P(H\|D)，因为假设不是集合 |
| **条件概率 P(D\|H)** | 给定假设下数据的概率 | → 所有流派共享的数学工具 |
| **逆概率问题 P(H\|D)** | 给定数据下假设的概率，即“逆”条件概率 | → 贝叶斯方法直接追求；频率主义认为无意义 |

---

### 第四层A：内曼-皮尔逊——频率主义假设检验

**哲学基础**：客观概率（长期相对频率）→ 只能推断长期错误率，不能推断假设的概率。

| 概念 | 定义与要点 | 关系与影响 |
|------|-----------|---------|
| **零假设 H0** | 最昂贵的那种错误所对应的假设，通常为“无效应” | → 被保护免于错误拒绝 |
| **备择假设 H1** | 与零假设对立的研究假设 | → 当拒绝 H0 时被接受 |
| **显著性水平 alpha** | 长期中当 H0 为真时错误拒绝它的比例，通常设为 0.05 | → 不是 P(H0\|数据) |
| **p 值** | P(获得当前或更极端数据 \| H0 为真) | → 常被误读为 P(H0\|数据) 或 P(错误) |
| **拒绝域** | 导致拒绝 H0 的检验统计量取值范围 | → 由 alpha 确定边界 |
| **I 类错误** | H0 为真时拒绝它，即弃真 | → 最受关注但只是错误的一种 |
| **II 类错误** | H0 为假时接受它，即纳伪 | → 通常被忽视 |
| **统计功效 Power = 1 - beta** | H0 为假时正确拒绝它的概率 | → 应预先设定并据此确定样本量 |
| **行为决策框架** | 统计推断 = 在两种行为（接受/拒绝）间做出长期最优决策 | → 不是关于信念或证据强度的 |
| **样本量确定** | 根据预期效应量、噪声水平和目标功效计算所需被试数 | → 功效分析是规范研究的必备步骤 |

**核心要点**：p 值不是 P(H0|数据)；alpha 控制的是长期错误率，而不是当前结论的可靠性。

---

### 第四层B：贝叶斯——主观概率推断

**哲学基础**：主观概率 → 统计推断应更新我们对假设的信念程度。

| 概念 | 定义与公式 | 关系与影响 |
|------|-----------|---------|
| **先验概率 P(H)** | 观察数据前对假设的信念程度；由研究者或模型设定 | → 是贝叶斯方法最受争议的环节 |
| **似然 P(D\|H)** | 给定假设下观察到数据的概率 | → 所有数据信息都包含在似然中 |
| **后验概率 P(H\|D)** | 观察数据后对假设的信念程度 | → 推断目标 |
| **贝叶斯定理** | P(H\|D) = P(D\|H) × P(H) / P(D)，即后验正比于似然 × 先验 | → 整个推断的数学基础 |
| **似然原则** | 所有来自数据的推断信息都包含在似然函数中 | → 经典统计违反此原则 |
| **可信度区间** | 后验概率分布中包含指定概率质量的区间 | → 可直接说“参数有 95% 概率在此区间内” |
| **贝叶斯因子** | 两个假设似然比，量化数据对两者的相对支持 | → 假设检验的贝叶斯替代方案 |
| **概率密度与概率** | 连续变量的单点概率为 0，概率密度描述区间概率 | → 连续参数的后验是概率密度分布 |
| **无信息先验问题** | 不存在真正的“无信息”先验；变量变换会改变先验的“无信息性” | → 似然学派因此放弃先验 |

### 第四层C：似然学派——证据的度量

**哲学基础**：区分三个根本不同的问题：应该做什么？应该相信什么？数据作为证据支持谁？

| 概念 | 定义与要点 | 关系与影响 |
|------|-----------|---------|
| **似然比** | 两个假设的似然之比；数据对两者的相对支持程度 | → 证据强度的核心度量 |
| **似然定律** | 数据支持能更好预测它的假设；似然比 = 证据强度 | → 独立于是否相信假设有概率 |
| **似然区间** | 包含似然值超过最大似然某个比例的参数范围 | → 可对应“相当强”和“强”证据 |
| **误导性证据概率** | 似然比为 k 地支持错误假设的概率 <= 1/k | → 即使无限样本也成立；与 p 值根本不同 |
| **弱证据概率** | 似然比在 1/8 到 8 之间，即证据不足的概率；随样本增大趋于 0 | → 可通过增加样本解决 |
| **证据、决策、信念三分** | 证据（似然比）与内曼-皮尔逊的决策、贝叶斯的后验信念是三个不同概念 | → 似然学派专注于“证据”这一独立问题 |

**为何 p 值不能度量证据**：

1. p 值依赖于“可能发生但未发生”的结果，例如研究者意图和停止规则。
2. 相同 p 值可对应截然不同的证据强度，例如大样本和小样本。
3. 多重比较校正改变 p 值，但不改变实际证据。
4. 单尾或双尾选择影响 p 值，但与证据无关。

**为何后验不能单独度量证据**：

- 后验 = 似然 × 先验；读者对研究者的先验未必感兴趣。
- 即使数据显示支持某假设，强烈的先验理由仍可使你保持不相信。

## 全书核心论点总结

1. **科学哲学层面**：一种研究传统要保持科学性，需要采纳波普尔的批判精神，同时理解库恩和拉卡托斯揭示的科学实践结构，避免滑向相对主义。

2. **统计推断层面**：许多经验研究中常用的内曼-皮尔逊方法常被误读，尤其是把 p 值当证据、忽视功效。贝叶斯方法提供了信念更新的数学框架，但先验问题难以回避。似然学派提出了一个更纯粹的问题：**数据作为证据，支持哪个假设？**

3. **两大板块的统一**：科学哲学告诉我们“什么是科学”，统计推断告诉我们“如何从数据中获取知识”。两者共同构成理解科学知识如何形成、受检验并从数据中获得支持的完整图景。
