# Fable Skill Smoke Test

This folder contains an end-to-end smoke test for the fable skill suite.

## Source

- Source material: `dev_notes/refs/科学哲学与统计推断.md`
- Scope: a minimal chain from the induction problem to Popperian falsifiability and corroboration.

## Artifacts

- `test/concept-map.md`: concept IDs, summaries, dependencies, and relationship table.
- `test/plan.md`: chapter plan, concept coverage matrix, acceptance criteria, and output paths.
- `test/drafts/chapter-01.md`: a compact fable draft following the writing skill.
- `test/reviews/chapter-01-review.md`: a review report following the review skill.

## Expected Pass Signal

- Concept IDs remain stable across all artifacts.
- The fable body does not name the target concepts.
- The explanation names the concepts and maps story elements back to them.
- The review gives a Pass or Revise decision with evidence.
